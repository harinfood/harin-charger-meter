# Harin Charger Meter

Aplikasi Android pemantau baterai dan charger (ampere, voltase, suhu, status pengisian).

Fitur:
- Meter arus (mA) dengan indikator mengisi / memakai baterai
- Daya (W), kecepatan pengisian (% per jam), perkiraan waktu penuh
- Voltase, suhu, level, status, jenis charger, kesehatan, teknologi baterai
- Picture-in-picture (PiP)
- Pengingat pengisian (cabut charger di target yang bisa diatur) dan pengingat baterai rendah
- Widget layar utama

Build: GitHub Actions (lihat `.github/workflows/build.yml`), artifact APK debug.
